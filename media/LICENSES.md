## Textures and client art

Bundled textures are uncompressed 32-bit BGRA TGA, 32 x 32 pixels, with
eight alpha bits. Statusbar and border are solid white tintable fills;
checked is an opaque two-texel ring with a transparent center; highlight
is translucent white. Rebuild with `python media/build_textures.py`;
verify without writing with `python media/build_textures.py --check`.

Gryphons use the installed client's
`Interface\\MainMenuBar\\UI-MainMenuBar-EndCap-Dwarf` texture.
Blizzard art is referenced only; no Blizzard artwork is distributed here.

## Icons

Every icon in RikUI is an asset, never a character of the font standing in for
one. The sources are the SVG files in `icons/`: a 24x24 view box, white, a
2.2-unit stroke with round caps and joins, solid fills where a shape needs
weight (the star, the skull's eyes, the talent nodes). The WoW client cannot
load SVG, only TGA and BLP, so `python media/build_icons.py` rasterises each
source to a white 32x32 BGRA TGA with the shape in the alpha channel, drawn at
eight times the size and scaled down for clean edges. The addon tints them with
`SetVertexColor` (three components: the fourth is the region's alpha).
`python media/build_icons.py --check` compares the committed bytes without
writing; the result depends on the Pillow version's resampling, so rebuild
after a Pillow upgrade.

The build script renders the SVG subset the icons use, so no SVG library is
needed, only Pillow: `path` (M L H V C Q Z, absolute and relative), `rect` with
`rx`, `circle`, `line`, `polyline`, `polygon`; `fill`, `stroke` and
`stroke-width` inherited from the `<svg>` element. Arcs are not supported; draw
them as cubic curves.

`media.lua` lists the icon names (`Media.Icons`); `Media.Icon(parent, name,
size, layer)`, `Media.SetIcon(texture, name)` and `Media.IconPath(name)` refuse
a name outside the list, because a typo would draw nothing in game.
`tests/icons.test.lua` keeps the list, the SVG sources and the built files in
step. New media files need a full client restart, not a reload.
