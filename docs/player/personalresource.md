# Personal resource display

## Personal resource display

This is the small health and resource display attached to your character in the game world. RikUI gives its health, power and alternate-power bars the same flat style as the rest of the interface.

![Health](render:prd-health) ![Power](render:prd-power)

Use the game's settings to control when this display appears. It follows the game's positioning.

## Turn the styling off

Disable **Personal resource** under **Settings → System → Modules** and reload to restore its usual appearance.

This display is separate from RikUI's movable [combat resource bar](combat-hud.md). It appears only when available and enabled in your game client.
