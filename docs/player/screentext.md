# Screen messages

## Zone names and warnings

Zone and subzone names, error messages and raid warnings use RikUI's font while keeping their usual positions and timing.

![Zone name](render:text-zone) ![Subzone name](render:text-subzone)

Errors remain easy to distinguish from zone titles and raid warnings. The game still decides which messages appear.

![Error message](render:text-error) ![Raid warning](render:text-raid)

Disable **Screen text** under **Settings → System → Modules** and reload to restore the original type.
