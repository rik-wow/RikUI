# Help improve RikUI

## Report a problem

Open an issue on [GitHub](https://github.com/rik-wow/RikUI/issues) and describe what happened, what you expected and how to repeat it.

Include the RikUI version, the game version and any error message. A screenshot helps with positioning or missing controls. Remove private chat and account details before sharing it.

For settings problems, note the module and setting involved. For quest guidance, include the quest name, objective, zone and the location where guidance went wrong.

## Suggest a change

Describe what you are trying to do and what would make it easier. Examples from ordinary play are useful, especially when a control is difficult to find or a layout gets in the way.

## Code contributions

The [repository](https://github.com/rik-wow/RikUI) contains the addon, installer, website and development instructions. Follow its contribution guide when preparing a pull request.
