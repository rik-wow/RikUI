# Quest timers

## Timed quests

Up to five timed quests appear above the quest tracker. Each row shows the quest and its remaining time.

![Timed objective](render:timers-timed)

The countdown becomes more prominent as time runs low, with red text near the deadline. The row disappears when the timer ends or the quest is no longer timed.

![Thirty-second warning](render:timers-warning) ![Final ten seconds](render:timers-final)

Leave some space above the tracker when arranging your interface so the timer rows have room.
