# Loss of control

## Control effects

The loss-of-control display appears when the game reports an effect such as a stun, fear or silence. It shows the effect and its remaining duration in a compact frame.

![Control effect](render:loc-effect) ![Remaining duration](render:loc-remaining)

It clears when the effect ends. Disable **Loss of control** under **Settings → System → Modules** and reload to restore the game's styling.
