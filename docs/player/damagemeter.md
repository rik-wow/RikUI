# Damage meter

## Read the meter

The damage meter lists players in coloured rows, with names and values kept together.

![Damage rows](render:meter-rows)

Use its header controls to choose the session and the type of information shown.

The meter uses the game's combat data. Changing RikUI's styling does not change the totals.

## Move it

Use `/rik move` to position the meter holder. Disable **Damage meter** under **Settings → System → Modules** and reload to use the game's appearance.
