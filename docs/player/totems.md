# Totems

## Active totems

Four compact buttons show your active totems. Each displays the totem's icon and remaining duration. Empty slots stay hidden.

![Four totem slots](render:totems-slots) ![Active duration](render:totems-duration)

Hover a totem to see its tooltip. Right-click to dismiss it when the game allows dismissal.

Use `/rik move` to position the totem group. Disable **Totems** under **Settings → System → Modules** and reload if you prefer the game's display.
