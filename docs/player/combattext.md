# Combat text

## Damage and healing numbers

RikUI uses the selected font for damage numbers in the game world. The **Combat text** settings page also exposes the game's available scrolling-text controls, including visibility and direction.

![Combat text settings](render:combattext-settings)

These game settings are shared across RikUI profiles.

## Change the font

Choose a font under **Settings → General**. Return to the character list for the world damage-number font to change.

Healing, resource gains and combat warnings appear according to your game settings.
