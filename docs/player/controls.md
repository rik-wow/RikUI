# Shared controls

## Buttons and fields

Buttons highlight when hovered. Checkboxes show whether an option is enabled, and dropdowns mark the selected choice. Disabled controls are dimmed.

![Button](render:ctl-button) ![Checkbox](render:ctl-checkbox) ![Dropdown](render:ctl-dropdown) ![Disabled control](render:ctl-disabled)

Click a text field to type. Sliders show the current value beside the control. Scrollbars indicate when more content is available. Colour controls open the colour picker.

![Text field](render:ctl-textfield) ![Slider](render:ctl-slider) ![Scrollbar](render:ctl-scrollbar) ![Colour control](render:ctl-colour)

## Using the settings keyboard controls

In RikUI settings, Tab and Shift-Tab move between controls. Enter or Space activates the current control. Left and Right adjust sliders or cycle dropdown choices.

An open dropdown supports Up, Down, Home and End. Enter selects the choice, and Escape cancels.

See [Settings and profiles](options.md) for navigation, search and reload controls.
