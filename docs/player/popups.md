# Confirmation popups

## Confirmations

Confirmation windows appear for actions that need another choice, such as accepting an item or entering text. Read the message and choose the appropriate button.

![Confirmation text](render:popup-confirm) ![Accept and cancel](render:popup-invite)

RikUI changes the frame's appearance. It does not automatically accept confirmations.

Popups with an item show its icon and information; text-entry popups keep an editable field. Timed confirmations keep their countdowns.
