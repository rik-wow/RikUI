# Breath and fatigue

## Breath, fatigue and feign death

These bars appear when the game starts a breath, fatigue or feign-death timer. Each has a label and a countdown bar.

![Breath](render:mirror-breath) ![Fatigue](render:mirror-fatigue) ![Feign death](render:mirror-feign)

The timer disappears when the condition ends. RikUI changes its appearance without changing how long you can remain underwater or in fatigue zones.

Use `/rik move` to place the timer group.
