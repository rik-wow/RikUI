# Chat bubbles

## Speech bubbles

Player and NPC speech bubbles use a dark background and RikUI's font. The game controls where they appear and how long they stay.

![Player speech](render:bubble-player) ![NPC speech](render:bubble-npc)

Use the game's chat-bubble options to choose which messages produce bubbles.

Disable **Chat bubbles** under **Settings → System → Modules** and reload to restore their usual appearance.
