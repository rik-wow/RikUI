# Event banners

## Level-ups and events

Level-up messages, event notifications, boss banners and objective banners share RikUI's window styling. Each keeps its own information and timing.

![Objective banner](render:banner-objective)

Some banners only appear for particular activities or client features. Recent banners can be reviewed from the side history where the game keeps one.

Disable **Banners** under **Settings → System → Modules** and reload to use the game's artwork.
